GitHub Pages Configuration Guide

GitHub Pages is serving raw source code instead of the compiled site. Follow one of these 2 simple methods to publish your live site:

Method 1: Change GitHub Pages Source (Easiest)
  1. Open your GitHub repository → Settings
  2. Click Pages in the left menu
  3. Under Build and deployment → Source:
    • Select GitHub Actions (Recommended)
    • OR select Deploy from a branch → Branch: main / Folder: /docs
Method 2: One-Command Terminal Deployment

Run this in your terminal to publish directly:

npm run deploy
